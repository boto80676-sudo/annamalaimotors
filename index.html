Publish to GitHub

After making Admin changes, enter your GitHub token and click Publish. The changes can then be committed to your GitHub repository and appear on your live website.

Your token is used only for this publish attempt and is not saved in localStorage. Use a fine-grained token with Contents: Read and write access to the target repository.

GitHub repository setup

Before publishing can work, configure your repository details in the JavaScript settings: repository owner, repository name, target branch and the HTML file path. The token input alone cannot identify where to publish.
